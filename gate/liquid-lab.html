Liquid effect lab

Three real liquid techniques, exaggerated. Which feeling is right?

A · Gooey metaballs

Soft shapes, blurred, then the alpha is thresholded — so droplets merge and stretch apart like mercury. This is "breathing" made liquid.

B · Noise displacement

A Perlin-noise map warps the shape's edges (feTurbulence + feDisplacementMap), animated — so the surface ripples and wobbles like water.

C · Both together

Metaballs merged, then noise-warped — the richest "living liquid." Slower and smaller amplitude would make it calm.
